# 기존 작업 폐기 기록

2026-09-21 사용자가 기존 작업 전량 폐기와 질문 중심의 재계획을 요청했다.
이에 따라 이 요청 이전의 모든 실험 계획·하네스·실행기·결과·그래프·결론은
현재 작업에서 폐기한다. 특정 결함이 확인된 파일에만 적용하는 조치가 아니다.

파일은 감사·복구를 위해 보관하지만, 새 계획의 코드 기반·측정 근거·권장사항으로
사용하지 않는다. 기존 실험 디렉터리와 results의 Complete/valid 표시는 당시
기록일 뿐 현재 채택 상태가 아니다. 기존 명령을 실행해 작업을 재개하지 않는다.

이 디렉터리에는 교체 전 설계서·보고서·실험 경계 문서의 원본과 SHA-256 목록을 보관한다.
그 외 기존 파일은 원래 위치에 남아 있으며 같은 폐기 상태가 적용된다.
이 조치는 파일의 영구 삭제를 수행한 것은 아니다.

현재 계획: [메모리 흐름 관찰](../../docs/memory-behavior-plan.md).
