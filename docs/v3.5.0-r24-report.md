# mimalloc v2.1.2 vs v3.4.3 vs v3.5.0 — r24 report

Execution status: Complete

## Scope

r24 is an isolated three-version epoch. It uses the same Rocky Linux 8 image,
benchmark binary, cpuset `0,2,4,6,8,10,12,14`, NUMA node 0, THP `madvise`,
upstream-default runtime policy, workload seed, and operation count within each
matched block. Earlier epochs are context only and are not pooled with r24.

Sources: v2.1.2 `43ce4bd7fd34bcc730c1c7471c99995597415488`, v3.4.3
`152fbf2634aeafca3774df791b0a77683035f076`, and v3.5.0
`18b08671c9302247bfb682286e6bf3cc1773f801`.

Pilot completed 45/45 valid runs. Core completed 225/225 valid runs: five cells,
three versions, and 15 complete matched repetitions. Measured durations were
calibrated to the frozen 10–30 second target range.

## Median paired throughput ratios

Ratio above 1 favors the numerator.

| Cell | v3.4.3 / v2.1.2 | v3.5.0 / v2.1.2 | v3.5.0 / v3.4.3 |
|---|---:|---:|---:|
| local fixed 64 B, 8 threads | 1.0370 | 1.0350 | 1.0096 |
| local mixed-wide, 1 thread | 0.9958 | 0.9979 | 0.9986 |
| local mixed-wide, 8 threads | 0.9855 | 0.9883 | 1.0008 |
| remote fixed 64 B, 4:4 | 0.9363 | 0.9622 | 0.9481 |
| remote mixed-wide, 4:4 | 1.0231 | 0.9276 | 0.9178 |

## Findings

* Local fixed-small favored both v3 releases over v2 by about 3.5–3.7% at the
  median. v3.5.0 and v3.4.3 were effectively close in all three local cells.
* Remote-free results were substantially more variable than local results.
  v3.5.0 median throughput was about 5.2% below v3.4.3 for fixed 64 B and 8.2%
  below for mixed-wide.
* The remote-free normal-approximation mean confidence intervals were wide and
  generally touched 1.0. These remote differences therefore require diagnostic
  follow-up before attributing them solely to allocator implementation changes.
* No invalid, crashed, allocator-mismatch, or incomplete core run occurred.

## Limitations

This epoch covers five core throughput cells under THP `madvise` and
upstream-default policy. It does not yet provide r24 latency-focused sampling,
perf counters, THP never/always, purge-delay, NUMA, secure-build, or large-page
comparisons. Smoke timings are not included as performance evidence.
