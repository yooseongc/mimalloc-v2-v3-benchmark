고정 dev3 SHA는 `d6716d33671c2f621b87be3c7ac016c6ba6b3c94`이며
`extern/mimalloc-dev3-d6716d33`의 clean checkout을 사용한다.

```powershell
# 새 namespace에서만 build → mode validation → smoke → pilot → freeze → measured
./observation/run_security_20261106.ps1
# 동결 이후 중단 재개만 필요할 때
./observation/run_security_20261106.ps1 -Stages measured
# raw 검증 / 집계 / 그림 생성 (Python + matplotlib)
python observation/analyze_security_20261106.py
# 본 측정 완료 후 별도 syscall / size class 진단 (새 namespace에서 1회만)
./observation/run_security_20261106.ps1 -Stages diagnostics
```

동결 namespace에서 build/pilot/freeze를 다시 실행하거나 원시 결과를 덮어쓰지 않는다.
새 측정은 새로운 namespace와 계획을 만든다. plan.json이 최종 Frozen 상태와
작업량/hash를 기록하며, 계획 문서의 pilot 이전 문구는 hash 보존을 위해 유지한다.

`results/security-20261106-v1`: local, concurrent, lifecycle raw (Git 제외).
`experiments/security-20261106-v1`: mode-validation, artifacts, plan, verification, 로그.
`build/security-20261106-v1`: 모드별 라이브러리, CMakeCache, 공통 실행파일.
`docs/security-20261106`: 전체 표·JSON·그림.

local_batch는 스레드를 생성하지 않는 새 프로그램이다. 기존 JSON 프로토콜의
검증 컨트롤러를 재사용하므로 local artifact만 `threads/artifacts.json` 경로에
저장되지만 raw와 보고서는 `local`로 명확히 구분한다.
