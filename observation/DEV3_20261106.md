## 소스 준비

`extern/mimalloc-v3.6.1`은 commit `56dc5eb80145f9a3ba7ca23d47c6a248b9d8586c`,
`extern/mimalloc-dev3-d6716d33`는 commit `d6716d33671c2f621b87be3c7ac016c6ba6b3c94`.
두 디렉터리는 clean Git checkout이어야 한다. branch HEAD를 다시 따라가지 않는다.
고정 Rocky 이미지가 로컬에 있어야 하며 측정 컨테이너는 네트워크를 사용하지 않는다.

```powershell
# 비어 있는 새 namespace에서만 전체 실행
./observation/run_dev3_20261106.ps1
# 중단 재개: 동결 hash와 완료 raw의 config/valid를 검사하고 건너뜀
./observation/run_dev3_20261106.ps1 -Stages measured
# 결과 검증 및 집계·그림 재생성 (Python 3 + matplotlib)
python observation/analyze_dev3_20261106.py
```

기존 동결 namespace에서 build/pilot/freeze를 다시 수행하지 않는다.
완전히 새 실험은 runner의 EXP/OUT/BUILD 및 계획 ID를 새 이름으로 복제해야 한다.
동일한 파일명에 다른 측정 결과를 덮어쓰지 않는다.

원시 결과는 `results/dev3-20261106-v1/{lifecycle,concurrent,threads}`에 있고
smoke/pilot/measured/collect를 구분한다. raw는 Git 제외이며 로컬에 보존한다.
artifact의 경로는 컨테이너 `/work` 기준이고 분석기는 현재 저장소 경로로 변환한다.
집계와 그림은 `docs/dev3-20261106`, 실행 로그와 hash 목록은
`experiments/dev3-20261106-v1`에 남긴다.

계획 문서는 pilot 이전 초안 문구를 유지하여 동결 hash를 보존한다.
최종 Design status 및 Frozen at은 plan.json이 권위 있는 기록이다.
