# page_reclaim_on_free 단일 변수 진단

2026-10-24, 실행 전 고정. 기본값 관찰과 별도 실행한다.
v3.5.3의 기본값 0과 v3.6.0의 기본값 1 변경이 처리 비용 차이를 설명하는지 확인한다.
v3.5.3/v3.6.0 각각 option 0/1, 1 KiB/4 KiB, 2쌍, 128 MiB 상한,
조건당 3회 = 24회. 객체 수는 본 관찰의 같은 조건과 동일하게 유지한다.
버전/옵션 순서는 seed 2026102401로 반복 블록 내 무작위화한다.
idle은 0.1초로 통일하며 이 진단으로 5초 반환을 비교하지 않는다.

upstream 소스·라이브러리와 timed workload는 수정하지 않는다. 준비 단계에만
실제 option getter 출력을 추가하고 각 버전의 헤더로 진단 binary를 빌드한다.
같은 버전에서 0/1은 동일 binary를 사용한다. 버전간 기본 성능 비교는 본 실험의
공통 binary를 근거로 삼고, 이 진단은 각 버전 내부 옵션 효과를 확인한다.

option 1은 다른 theap의 페이지 회수를 허용하므로 반복 원격 해제의 atomic 처리와
페이지 재사용·보유 방식이 바뀔 수 있다. 개선 방향이나 크기는 미리 단정하지 않는다.
payload/체크섬/작업 수/affinity/로드 경로/SHA/swap/throttle 검증은 본 실행과 같다.
실제 getter가 요청 값과 달라지면 실패한다. 결과·오류를 보존한다.
한 변수의 효과로 버전 사이 모든 변경을 설명했다고 주장하지 않는다.
